# Third-party components

This project uses third-party open-source software and a pre-trained speech recognition model. Review each upstream project's license before redistribution.

- sherpa-onnx: https://github.com/k2-fsa/sherpa-onnx
- PyAudioWPatch: https://github.com/s0d3s/PyAudioWPatch
- NumPy: https://numpy.org/
- PyInstaller: https://pyinstaller.org/
- ASR model: sherpa-onnx-streaming-zipformer-en-2023-06-26, distributed from the sherpa-onnx model releases.
